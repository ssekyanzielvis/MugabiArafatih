3.3 Content Management
All visitor website content is dynamically loaded from Supabase database, allowing real-time updates via Admin Dashboard.

4. Admin Dashboard Specifications
4.1 Access & Authentication
Login System: Email/password authentication via Supabase Auth

Role Management: Super Admin can register/remove other admins

Session Management: Secure token-based sessions

4.2 Dashboard Modules

2. KINSMEN PAGE EDITOR
   • Definition Text Editor
   • Title Configuration
   • Description Editor
   • Media Management for left column
   • Live Preview

   • Title & Description Editor
